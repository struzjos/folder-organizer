# Plans

- Every plan, current or future, is a file here named `NNN-short-name.md`.
  - `001`–`009`: core app.
  - `010+`: feature ideas.
- Each plan starts with a `Status:` line: `Idea`, `Planned` or `In progress`.
- When a plan is fully implemented and verified, move it to `done/` and add `Implemented: YYYY-MM-DD` with a short note on any deviations from the plan.
- New ideas get their own plan file instead of living only in chat or commit messages.
